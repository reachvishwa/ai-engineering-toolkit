# About

## Who this is for

This site documents my practical work as an AI Engineer: how I use Claude Code, MCP servers, and traditional data tooling (Power BI, Qlik, SQL, Python) together to build reliable, explainable systems — plus how I evaluate and deploy LLMs, including local inference with NVIDIA NIM.

## What you'll find here

- **Claude Code Skills** — reusable skill definitions I use day to day, documented so others can adapt them.
- **MCP Servers** — configuration and usage notes for Model Context Protocol servers that connect AI assistants to real systems.
- **Power BI & Qlik** — semantic modelling, DAX, and BI development patterns, including AI-assisted workflows.
- **Python & SQL** — the scripting and query patterns that glue everything together.
- **NVIDIA NIM** — running and evaluating models via NVIDIA Inference Microservices.
- **LLM Comparisons & Prompts** — practical, opinionated comparisons and reusable prompt templates.

## How this site is built

- **MkDocs** + **Material for MkDocs** for the site generator and theme.
- **Markdown only** — no React, Vue, or custom frontend build step.
- **GitHub Actions** rebuilds and redeploys the site automatically on every push to `main`.
- **GitHub Pages** hosts the static output.
