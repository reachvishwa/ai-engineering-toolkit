## Introduction

This site is a living knowledge base documenting practical, hands-on AI engineering work — reusable **Claude Code skills**, **MCP server** integrations, **Power BI / Qlik / SQL / Python** data engineering patterns, and applied use of **NVIDIA NIM** for local and hosted inference.

Everything here is written the way I'd want to hand it to a colleague: a clear problem statement, a working solution, runnable code, and honest notes on trade-offs. New content is added simply by dropping a Markdown file into a folder — the site rebuilds and redeploys automatically on every push.
